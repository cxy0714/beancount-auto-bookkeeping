# 原始数据（虚拟）

本目录中的所有账单均为演示用虚拟数据，不对应任何真实用户或交易。
目录结构保持真实导出时的组织方式：

```text
原始数据/
├── 支付宝/{账期}/*.csv
├── 支付宝基金/{账期}/*.pdf
├── 微信/{账期}/*.xlsx
├── 京东/{账期}/*.csv
├── 示例银行A/{账期}/交易流水明细*.pdf
├── 示例银行B/{账期}/示例银行B交易流水*.pdf
├── 示例银行C/{账期}/*.pdf
├── 示例银行A信用卡/{月账期}/*.PDF
└── 支付宝余额/{账期}/*.pdf
```

真实使用时，请按对应来源的导出方式替换文件。
